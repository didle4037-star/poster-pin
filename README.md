Scatter and place posters on walls, curved surfaces, and strings in Blender, with layers, tape, pins, and clips.

Poster Pin is part of **Print & Pin**. It can be used on its own or together with **[Poster Print](https://github.com/didle4037-star/poster-print)**: Poster Print creates the source posters, and Poster Pin arranges them in the scene.

## Features

- Scatter poster meshes from a source collection onto walls, floors, and curved surfaces.
- Hang posters along curves or selected mesh edges.
- Arrange posters in layers and adjust rotation, spacing, overlap, and paper lift.
- Place or grab individual posters interactively, then move, rotate, and scale them.
- Add tape, pins, and clips; control placement areas with painting tools.
- Convert the results to a mesh when the arrangement is finished.

## Installation

1. Open this repository's **Releases** and download **`Poster_Pin_v1.41.zip`**.
2. In Blender, open **Edit → Preferences → Add-ons** and choose **Install from Disk** from the menu.
3. Select the downloaded file and enable **Print & Pin · Poster Pin**.
4. In the 3D Viewport, press **N** to open the sidebar and choose **Poster Pin**.

This release uses the legacy add-on format. Use the attached installation archive rather than assuming GitHub's automatically generated source ZIP is the installation package.

## Quick start

1. Prepare flat poster mesh objects in a collection. You can use your own posters or build them with Poster Print.
2. In **Poster Pin**, choose the source poster collection.
3. Select a wall/floor mesh, a curve, or the desired mesh faces/edges.
4. Use the scatter button for the selected target.
5. Adjust the arrangement, layers, attachments, or individual poster placements.
