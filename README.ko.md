# Print & Pin · Poster Pin

[English](README.md)

## 소개 영상

[![Print & Pin introduction video](https://i.ytimg.com/vi/AwLWuNOE6Js/hqdefault.jpg)](https://youtu.be/AwLWuNOE6Js)

[Watch: I Made 2 Blender Add-ons That Turn Images Into a Poster Wall | Print & Pin](https://youtu.be/AwLWuNOE6Js)

Poster Pin은 Blender에서 포스터를 벽·곡면·줄에 배치하고 레이어와 부착물을 조절하는 애드온입니다.

**Print & Pin** 시리즈의 도구로, 단독으로 사용하거나 **[Poster Print](https://github.com/didle4037-star/poster-print)**와 함께 사용할 수 있습니다. Poster Print로 원본 포스터를 만들고 Poster Pin으로 장면에 배치하는 흐름을 구성할 수 있습니다.

## 주요 기능

- 컬렉션에 있는 포스터 메시를 벽·바닥·곡면에 자동 배치합니다.
- 커브나 선택한 메시 엣지를 따라 포스터를 걸 수 있습니다.
- 레이어, 회전, 간격, 겹침과 종이 들림을 조절합니다.
- 포스터를 클릭해 직접 배치하거나 이동·회전·크기를 조정합니다.
- 테이프·핀·클립을 추가하고 페인팅으로 배치 영역을 제어합니다.
- 배치가 완료되면 결과를 메시로 변환할 수 있습니다.

## 버전과 환경

- 제작자: **G_ni**
- 코드에 기록된 버전: **1.41.0**
- 패키지에 선언된 최소 Blender 버전: **5.2.0**
- UI 언어: **영어 / 한국어**

위 Blender 버전은 소스 메타데이터 기준이며 실제 호환성 테스트 결과를 의미하지 않습니다.

## 설치

1. 이 저장소의 **Releases**에서 **`Poster_Pin_v1.41.zip`**를 내려받습니다.
2. Blender에서 **Edit → Preferences → Add-ons**를 열고 메뉴의 **Install from Disk**를 선택합니다.
3. 파일을 선택해 설치한 다음 **Print & Pin · Poster Pin**을 활성화합니다.
4. 3D 뷰포트에서 **N**을 눌러 사이드바의 **Poster Pin** 탭을 엽니다.

현재 배포본은 기존 애드온 형식입니다. GitHub에서 자동 생성하는 소스 ZIP과 구분하여, 릴리스에 첨부된 설치용 ZIP을 사용하세요.

## 빠른 시작

1. 평평한 포스터 메시를 컬렉션에 준비합니다. 직접 만든 포스터나 Poster Print 결과를 사용할 수 있습니다.
2. **Poster Pin**에서 원본 포스터 컬렉션을 지정합니다.
3. 벽·바닥 메시, 커브 또는 사용할 면·엣지를 선택합니다.
4. 선택 대상에 맞는 배치 버튼을 누릅니다.
5. 레이어, 부착물과 포스터별 배치를 조정합니다.
